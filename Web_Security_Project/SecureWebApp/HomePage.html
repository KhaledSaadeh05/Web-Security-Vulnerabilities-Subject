Project Overview

This is the secure version of the Web Security project. Every vulnerability present in the vulnerable version has been fixed here using industry-standard best practices.

Protections are in place for: Information Disclosure, SQL Injection, and XXE Injection.

Security Measures Applied

Parameterized Queries

All database queries use prepared statements — user input never touches SQL syntax.

Input Validation

Every input is validated against an allowlist before being processed.

Entity Processing Disabled

XML parsing rejects DOCTYPE and external entity declarations entirely.

No Sensitive Exposure

Error messages are generic. Admin and debug routes do not exist.

Protected Pages

1. Information Disclosure — Fixed

Admin and debug routes return 404. Error messages reveal no internal details. Debug panels and stack traces are completely removed.

Open Page

2. SQL Injection — Fixed

Login and product queries use parameterized statements. Category input is validated against an allowlist before any query runs.

Open Page

3. XXE Injection — Fixed

All XML endpoints scan for DOCTYPE, SYSTEM, ENTITY, and XInclude patterns and reject them with a security message before any parsing occurs.
