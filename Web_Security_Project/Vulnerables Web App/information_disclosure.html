Information Disclosure

A common web security vulnerability in which sensitive or internal information is exposed to unauthorized users.

Overview

Information Disclosure happens when a web application reveals data that should not be publicly available. This may include system details, configuration information, file paths, developer messages, backup files, or internal pages.

Even if the attacker cannot directly change data, exposed information can still help in understanding the structure of the system and identifying further weaknesses.

Examples of Exposed Information

  • Error messages that reveal file paths or query details
  • Debug pages left accessible to users
  • Backup files stored inside public directories
  • Configuration files containing usernames or passwords
  • Hidden internal paths listed in public resources

Why It Is Dangerous

This vulnerability is dangerous because attackers can collect valuable technical information about the application and the server environment. That information can be used to support additional attacks or make other vulnerabilities easier to exploit.

Prevention

  • Use generic error messages for users
  • Disable debug mode in production
  • Do not store backup files in public folders
  • Restrict access to internal resources
  • Review exposed files and directories regularly
