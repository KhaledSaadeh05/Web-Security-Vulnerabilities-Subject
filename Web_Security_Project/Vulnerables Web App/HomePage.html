Vulnerabilities Web App

An educational web application designed to demonstrate common web security vulnerabilities in a controlled environment.

Start Exploring

Project Overview

This web application was developed as part of a Web Security project. It demonstrates how security flaws may appear when proper protection is missing.

The application includes three vulnerabilities: Information Disclosure, SQL Injection, and XXE Injection.

Project Objectives

Understand the Vulnerability

Explain how each vulnerability works.

Observe the Impact

Show the effect of insecure coding.

Compare Later

Compare with the secure web application.
